# Reporting a vulnerability

Email [security@morpho.org](mailto:security@morpho.org) to report a vulnerability
in the Go calldata verifier. Do not open a public GitHub issue, discussion,
or pull request for a security report.

Include the affected Go module version or commit, the impact, and steps to
reproduce. Use redacted or synthetic data; do not send credentials, private
keys, or signatures that can still be used.

For deployed Morpho contracts, use the
[Morpho bug bounty on Immunefi](https://immunefi.com/bug-bounty/morpho/information/).
If you are unsure where the issue originates, email security@morpho.org.
